# Tampa persistence-carrier discrimination v1

## Central ecological question

> **When a foundation species remains present despite quantitative change, what actually carries persistence forward: stored internal state, self-engineered physical state, or community substitution?**

This is the prospective synthesis question for Tampa.

The programme does **not** treat "resilience" as one latent quantity and does not assume that one mechanism must explain every bay or every state dimension.

## Why this is sharper than a TNC paper

Three component ideas are already established:

1. below-ground carbohydrate reserves can predict later seagrass performance;
2. foundation species can engineer their local physical environment;
3. alternative species can preserve some functions after focal-species decline.

The unresolved problem is whether these are interchangeable stories or distinguishable **persistence carriers** in the same long-monitored ecological system.

Tampa can discriminate among them because the annual record already shows that the same coarse recorded-presence state can contain very different quantitative states.

## Carrier A — stored internal state

Measured candidates:
- rhizome TNC;
- meristem / apex density;
- below-ground biomass and architecture;
- short-term reserve trajectory.

Decisive test:
- within-node centered anchor TNC predicts future same-meter *Thalassia* state after baseline local state and node identity are represented.

Interpretation if supported:
> future capacity is partly stored in a biological state not visible from current above-ground condition alone.

Interpretation if unsupported:
> carbohydrate reserve is not the principal hidden carrier under this design; do not retune the endpoint.

## Carrier B — self-engineered physical state

Measured candidates:
- within-canopy versus reference flow attenuation;
- within-canopy versus reference optical environment.

Required two-link evidence:
1. the canopy generates a measured physical contrast under a paired reference;
2. that measured engineered state predicts later quantitative *Thalassia* state after ambient forcing and baseline state are represented.

Interpretation if supported:
> persistence is partly carried outside the plant body, in an environment maintained by the meadow itself.

This is distinct from merely showing that dense seagrass occurs in benign sites.

## Carrier C — community substitution / functional continuity

Candidate state:
- persistence or increase of alternative habitat-forming seagrasses when focal *Thalassia* declines.

A true community carrier requires more than continued vegetation occupancy.

Required evidence:
1. focal *Thalassia* state declines;
2. alternative-species canopy persists or increases;
3. a directly measured ecological function is retained.

Without step 3, use:
> community occupancy continuity

Do not use:
> functional insurance

## Carrier D — persistent site template

This is the principal non-mechanistic alternative.

Examples:
- stable microsite quality;
- unresolved sediment/hydrodynamic structure;
- long-lived spatial heterogeneity not caused by the current meadow.

Cross-node associations are compatible with this alternative.

Within-node, temporal and paired physical-reference tests are therefore given higher mechanistic weight.

## Evidence graph

The programme is evaluated as a graph rather than one omnibus p-value.

### Internal-state path

external forcing
-> reserve change
-> future local *Thalassia* state

Required evidence:
- forcing -> post-TNC conditional on pre-TNC;
- TNC -> future state conditional on baseline visible state;
- strongest support if reserve trajectory adds information beyond current TNC.

### Engineered-state path

current meadow
-> measured physical attenuation
-> future local *Thalassia* state

Required evidence:
- paired inside/reference physical contrast;
- attenuation -> future state conditional on ambient exposure and baseline state.

### Community-continuity path

focal quantitative decline
-> alternative canopy continuity
-> retained measured function

Required evidence:
- no inference of functional insurance from species occurrence alone.

## Predeclared interpretation matrix

### A supported; B/C unsupported or unmeasured
Use:
> persistence carries a measurable internal reserve component.

Do not claim a universal mechanism.

### B supported after direct physical attribution
Use:
> part of future persistence is carried in a self-engineered physical environment.

### A and B both supported
Use:
> persistence is distributed across internal and external state carriers.

Do not rank mechanisms by p-value.

### Focal species declines, alternative canopy persists, function retained
Use:
> community substitution carries part of ecosystem function despite focal-species decline.

### All measured carriers unsupported with adequate precision
Use:
> the observed coarse persistence is not explained by the measured reserve, engineered-state or community-carrier candidates; persistent site template or another hidden state remains.

This is a scientifically useful falsification, not a reason to reopen retrospective variable mining.

## Strong paper-level result

The strongest possible synthesis is:

> **A foundation species' future is not fully encoded in whether it is currently present. Persistence can be carried by state stored inside organisms, state engineered into the local environment, and state retained at the community level; these carriers can be measured and tested separately.**

That statement is allowed only if at least two carrier classes receive direct prospective support.

If only the internal reserve path is supported, keep the manuscript at the narrower state-augmentation claim.

## Why the question matters

Most monitoring compresses ecological systems into observable state variables such as extent, cover, occupancy or biomass.

The Tampa programme asks a different question:

> **what variable actually carries future capacity when the visible state has not yet changed?**

This is relevant wherever long-lived foundation species can remain present while regenerative capacity, physical feedbacks or community composition change.

## Hard boundaries

- No new retrospective mechanism mining from the annual Tampa table.
- No use of binary re-recording as demographic recovery.
- No post-outcome threshold tuning.
- No p-value ranking among carriers.
- No functional-insurance claim without a measured function.
- No causal self-engineering claim without a paired physical counterfactual.
- No ecological-memory claim from a cross-node association alone.
