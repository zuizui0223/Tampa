# Tampa decisive-test priority v1

## Decision

The first outcome-bearing prospective mechanism test should be:

> **baseline rhizome total non-structural carbohydrate (TNC) -> future quantitative Thalassia change**

under the four-bay prospective design.

This does not demote hydrodynamic self-facilitation or community functional insurance. It sets the execution order.

## Why TNC first

### 1. It attacks the hidden-state question directly

The retrospective Tampa result is not simply decline.

It is:

> coarse recorded presence can persist while finer quantitative meadow state deteriorates.

A below-ground reserve state is therefore a direct candidate for the hidden capacity allowing a sessile foundation species to remain present despite above-ground degradation.

### 2. The prospective sampling frame is already strong

The four-bay response-independent preflight identifies:

- Old Tampa Bay: 8 recent Thalassia-positive stable nodes;
- Middle Tampa Bay: 11;
- Lower Tampa Bay: 14;
- Boca Ciega Bay: 8;
- total: **41**.

All eight Boca Ciega nodes have at least three positive meter marks, so the frozen q25/q50/q75 core geometry applies directly.

The approximate 80%-power detectable partial correlation improves from about **0.49** in the three-bay 33-node frame to about **0.44** in the four-bay 41-node frame.

### 3. It is cleaner than the hydrodynamic attribution test

The hydrodynamic programme requires:

- multi-week synchronized velocity deployment;
- inside-canopy and upper-reference measurement;
- physically adequate burst sampling;
- a nested matched bare-bed counterfactual;
- minimum 12 qualified bare controls with >=3 per core bay;
- then a second future biological link.

That programme is scientifically valuable but has more failure points.

TNC requires one synchronized <=28-day biological campaign plus the paired quantitative baseline survey and future fixed-transect response.

### 4. It separates resistance capacity from current condition

Primary model remains:

~~~text
future_delta_frequency
  ~ baseline_frequency
  + baseline_Braun_Blanquet
  + rhizome_TNC
  + water_body
~~~

The question is therefore not whether healthier meadows have more carbohydrate.

It is:

> **does below-ground reserve state contain prospective information about future change after present above-ground condition is already known?**

## Four-bay decision

Boca Ciega Bay is included **now**, before future outcome-bearing sampling.

Reason:

- adds eight eligible recent nodes;
- all eight have strong spatial core geometry;
- provides a fourth ecological context not selected because it recently declined;
- reduces the risk that the mechanism is inferred only from the three bays emphasized by post-2016 degradation.

This is a generality decision, not a rescue.

## Confirmatory gate

Primary four-bay claim requires:

- >=36 analyzable nodes total;
- >=6 analyzable nodes in each bay;
- all primary TNC samples collected within one <=28-day campaign;
- each TNC sample paired to a baseline fixed-transect survey within +/-14 days;
- one frozen HPLC-based TNC workflow;
- future quantitative endpoint opened only after baseline predictor/QC freeze.

The six-node per-bay floor is a representation guardrail that allows limited field/QC attrition in the two smallest planned bays; the >=36 total-node requirement carries the main precision burden.

If those replication gates fail, the result becomes pilot/sensitivity evidence rather than a decisive null.

## Execution order

1. finalize permissions and contemporaneous 4-bay node registry;
2. run the response-independent Thalassia tissue/HPLC matrix pilot;
3. freeze core diameter/depth, offset geometry and preservation workflow;
4. schedule one synchronized <=28-day field campaign;
5. collect TNC + leaf N/P + meristem/apex diagnostics;
6. perform paired quantitative baseline survey;
7. freeze baseline dataset/QC and primary model code;
8. wait for the prespecified future transect survey;
9. open future endpoint once and run the frozen model.

## Second mechanism line

Hydrodynamic self-facilitation remains the second prospective line.

It should proceed in parallel only if instrumentation capacity does not compromise the TNC campaign.

Do not combine TNC x attenuation in the primary model after seeing outcomes.

## Third mechanism line

Community functional insurance is a complementary organizational-level mechanism.

It becomes strongest after direct velocity measurements exist because occupancy insurance is already established, while functional equivalence is not.

## Paper-level interpretation

If TNC predicts future quantitative state:

> measured below-ground reserve state is a prospective biological buffer beyond current above-ground condition.

If TNC is null with adequate four-bay precision:

> the primary measured reserve mechanism is weakened; proceed to the independently frozen physical and community-buffer hypotheses without redefining TNC.

The value of the design is that a null closes a mechanism rather than spawning another retrospective rescue.
