# Tampa resilience-debt terminology and evidence boundary v1

## Why this boundary is needed

The Tampa biological pattern is tempting to describe as a "resilience debt":

- coarse *Thalassia* occurrence can remain recorded;
- finer quantitative state can deteriorate;
- prospective work will measure hidden buffer state.

But resilience debt has a more specific ecological meaning than "hidden degradation."

Johnstone et al. (2016; DOI 10.1002/fee.1311) define resilience debt as a loss of resilience that is not apparent until disturbance reveals reduced capacity for recovery. The concept is tied to erosion or misalignment of ecological memory / legacies and to **future recovery capacity**, not merely to a low hidden state variable.

Recent applications retain that logic (for example Taylor et al. 2025, *Ecological Applications*, DOI 10.1002/eap.70125).

Therefore Tampa uses a stricter terminology ladder.

## Current retrospective result

Already supported:

> coarse recorded occurrence and quantitative meadow condition can decouple.

Allowed terms:

- state decoupling;
- cryptic quantitative degradation;
- persistent occurrence with quantitative deterioration.

Not allowed from the retrospective record alone:

- resilience debt;
- recovery debt in the ecological-resilience sense;
- exhausted resilience;
- imminent collapse.

## Prospective stage 1 — hidden buffer depletion

The event-stress programme can establish a more mechanistic state:

1. a frozen external event exposure predicts lower post-event rhizome TNC after pre-event TNC is represented;
2. *Thalassia* remains recorded at the synchronized post-event baseline survey.

If both occur, the allowed interpretation is:

> **measured internal reserve was depleted while coarse occurrence persisted.**

Preferred compact phrase:

> **hidden buffer depletion under persistent occurrence.**

This is stronger than retrospective state decoupling.

It is still not automatically resilience debt.

## Prospective stage 2 — buffer state predicts later quantitative trajectory

The independently frozen TNC programme asks whether lower post-event / baseline TNC predicts less favorable future quantitative *Thalassia* change.

If event -> TNC depletion and TNC -> future quantitative change are both supported:

> the data are consistent with a sequence in which an environmental event consumes a hidden reserve buffer, while the remaining reserve state contains information about later meadow trajectory.

This can be described as:

- buffer depletion with delayed quantitative consequence;
- a candidate debt-like persistence mechanism;
- hidden loss of reserve capacity that precedes later quantitative deterioration.

Do **not** automatically relabel it "resilience debt sensu Johnstone et al."

The future endpoint is quantitative meadow change, not recovery after a separately characterized subsequent disturbance.

## What would be required for a strict resilience-debt claim

A stronger resilience-debt test requires an additional recovery-capacity component.

At minimum:

1. **pre-disturbance buffer state** is measured;
2. a subsequent disturbance is independently characterized rather than inferred from the biological response;
3. the system's post-disturbance recovery trajectory is measured;
4. lower pre-disturbance buffer state predicts reduced recovery after disturbance;
5. the reduced recovery capacity was not obvious from coarse pre-disturbance occurrence alone.

Example future endpoint families could include:

- recovery rate of focal frequency after an independently observed acute disturbance;
- time to regain pre-disturbance quantitative state;
- probability of regaining a predeclared fraction of pre-disturbance cover/frequency;
- regenerative shoot production after a characterized disturbance.

No such strict recovery endpoint is currently a Tampa primary test.

## Node-level reporting without inventing a threshold

Do not define a post-hoc TNC cutoff for "debt."

For nodes with paired event/TNC data, report:

- pre-TNC;
- post-TNC;
- delta TNC;
- coarse recorded state at the synchronized post-event baseline;
- future quantitative change.

A node can be described factually as:

> recorded-positive after the event despite measured reserve depletion

when those observations occur.

Do not classify nodes into "debt / no debt" using a data-chosen threshold.

## Relationship to ecological memory

TNC is a **material biological state** that can carry effects of past carbon balance.

Genet identity, rhizome reserve and meristem state are not interchangeable kinds of memory.

The Tampa programme therefore avoids the vague statement:

> the meadow has ecological memory.

Instead it asks which measurable legacy/state matters:

- stored carbon reserve;
- regenerative meristem state;
- engineered physical environment;
- community functional continuity.

If a strict resilience-debt claim is ever made, it must identify which of these legacies has been eroded and how that erosion changes recovery after a later disturbance.

## Conservation boundary

Before a strict recovery-capacity test exists, management may use validated buffer measurements only as **prospective vulnerability indicators**, not as a diagnosed resilience debt.

Allowed after validation:

> occupied meadow with low measured reserve / weak measured engineering state merits closer follow-up.

Not allowed:

> this meadow has crossed a resilience threshold.

No current Tampa analysis identifies such a threshold.
