# Estuaries and Coasts submission checklist v1

Guideline source checked 2026-09-28.

## Article type and editorial fit

- [x] Target journal: *Estuaries and Coasts*
- [x] Target article type: Original Article
- [x] Results and Discussion are separate
- [x] General ecological question leads the paper
- [x] NPS external comparison remains in the main text to reduce “strongly place-based / primarily descriptive” desk-rejection risk
- [x] Mechanism-null analyses are secondary rather than the novelty claim
- [ ] Final cover letter explicitly states why the manuscript is an Original Article rather than a place-based Brief Report

## Abstract and keywords

- [x] Abstract within 150–250 words: **230 words**
- [x] 4–6 keywords: **6**
- [x] No undefined abbreviations in Abstract
- [x] No citations in Abstract

## Statistics and language

- [x] Manuscript avoids “statistically significant”
- [x] Manuscript avoids star notation
- [x] Actual p values are reported for main inferential contrasts
- [x] Sample sizes / target-year counts are reported for headline predictive contrasts
- [x] Recorded loss is not called demographic extinction
- [x] NPS analysis is labelled post-hoc
- [x] Mechanism remains explicitly unresolved

## References

- [x] Name–year citation system
- [x] Parenthetical citations use comma before year
- [x] Reference list alphabetized by first author
- [x] DOI links included where available
- [x] Reference entries reformatted toward APA 7 / journal guidance
- [ ] Final Word export: verify italics, en dashes, author punctuation, and any issue numbers

## Figures

- [x] Four main figures
- [x] Journal-specific renderer outputs 174 mm wide artwork
- [x] EPS vector output
- [x] 600 dpi TIFF output
- [x] RGB/accessible QA preview
- [x] 8–12 pt sans-serif lettering target
- [x] No overall titles/captions inside submission artwork
- [x] Lowercase panel letters
- [x] Lines/markers/hatching reduce reliance on color alone
- [x] Captions stored in manuscript text
- [ ] Final visual QA of ESCO EPS/TIFF package
- [ ] Confirm all figure files named Fig1–Fig4 at upload
